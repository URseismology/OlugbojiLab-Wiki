# AI Documentation System for Advanced Seismic Tomography and MCMC Simulations

## 1. Project Overview

### Introduction
The `ROOT` subsystem is a sophisticated framework dedicated to advanced seismic tomography and Markov Chain Monte Carlo (MCMC) simulations, specifically tailored for African geological contexts. The system comprises two main modules: `shared` and `jlegre_test`.

- **Shared Module**: Provides a robust foundation with specialized sub-modules for 2D rjMCMC simulations, resource optimization using SLURM and OpenMPI, synthetic data generation, and comprehensive result visualization.
- **jlegre_test Module**: Focuses specifically on 2D random jump MCMC simulations for African rift zones, including SLURM scripts for parallelizing MCMC instances, synthetic data generation tools, and visualization utilities.

### Key Features
- **Seismic Tomography**: Advanced algorithms for seismic wave propagation analysis.
- **MCMC Simulations**: Efficient Markov Chain Monte Carlo methods for model optimization.
- **Parallel Processing**: Utilizes SLURM and OpenMPI for efficient parallel execution.
- **Synthetic Data Generation**: Tools to generate synthetic data for model validation.
- **Visualization Utilities**: Comprehensive visualization tools for result interpretation.

## 4. Workflows

### Data Flow
1. **Data Preparation**:
   - **syn_data/**: Synthetic data is generated using `generate_syn_data.m`.
   - **test/paths.dat**: Paths to various data files are specified.
   - **test/receivers.dat** and **test/sources.dat**: Receiver and source locations are defined.
   - **test/observations.dat**: Observed seismic data is loaded.

2. **Model Initialization**:
   - **CreateNewModel.m**: A new model is initialized based on the synthetic or observed data.
   - **CreateNewModel_Afr.m**: Initializes a model specific to African regions.

3. **MCMC Simulation**:
   - **prepare_chains.sh**: Chains are prepared for submission.
   - **submit_chain_bh.slurm**, **submit_chain_br.slurm**, **submit_chain_ex.slurm**: SLURM scripts submit the chains to the scheduler.
   - **run_MCMC*D.slurm** and **run_rj*DMCMC.slurm**: MCMC simulations are executed using SLURM.

4. **Forward Steps**:
   - **ForwardStep.m**: Forward steps in the simulation predict seismic wave propagation based on the current model.

5. **Model Update and Acceptance**:
   - **PickAction.m**: Selects actions to perturb the model.
   - **AcceptOrNot.m**: Determines whether the new model should be accepted or rejected based on acceptance criteria.

6. **Result Visualization**:
   - **plot_results.m**: Visualizes the results of MCMC simulations.
   - **plot_simulation.m**: Visualizes simulation results.

### Example Workflow
1. **Generate Synthetic Data**:
   ```sh
   matlab -nodesktop -nosplash -r "generate_syn_data; exit"
   ```

2. **Initialize Model**:
   ```sh
   matlab -nodesktop -nosplash -r "CreateNewModel_Afr; exit"
   ```

3. **Prepare and Submit Chains**:
   ```sh
   ./prepare_chains.sh
   sbatch submit_chain_bh.slurm
   ```

4. **Run MCMC Simulations**:
   ```sh
   sbatch run_MCMC*D.slurm
   ```

5. **Visualize Results**:
   ```sh
   matlab -nodesktop -nosplash -r "plot_results; exit"
   ```
