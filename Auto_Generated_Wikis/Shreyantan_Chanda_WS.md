## 4. Workflows

### Data Flow Overview
The data flow in the SRTFISTA Seismic Data Analysis System is designed to transform raw seismic data into insightful models through a series of processing steps. Here's a high-level overview of the workflow:

1. **Data Loading**:
   - Raw seismic data is loaded from `1_data/RF/` using functions like `irisFetch.m`.
   
2. **Preprocessing**:
   - Data is preprocessed to enhance signal quality. This includes filtering, interpolation, and noise reduction.
   - Functions such as `crop.m`, `interpbl.m`, and `getSnr.m` are used for these steps.

3. **Receiver Function Computation**:
   - Receiver functions are computed using specialized functions like `sparse_inverse_radon_fista.m`.
   - Parameters are set up using scripts in the `3_Workflw/` directory, such as `a*_setupparameters.m`.

4. **Radon Transform**:
   - The Radon transform is applied to detect key seismic features, particularly discontinuities like the Moho boundary.
   - The FISTA algorithm is used for sparse inverse Radon transform, implemented in `b*_fista_results.m`.

5. **Visualization and Reporting**:
   - Visualizations are generated using functions from the `m_map/` module, such as `m_proj.m` and `m_coast.m`.
   - Results are saved to `1_data/SRTFISTA/` for further analysis and reporting.

### Detailed Workflow
#### Step 1: Data Loading
- **Script**: `CompositeTestFile.m`
- **Functions Used**: `irisFetch.m`, `readsac.m`
- **Description**: Raw seismic data is fetched from the IRIS Data Management Center or local `.sac` files. The data is loaded into memory for further processing.

#### Step 2: Preprocessing
- **Script**: `CompositeTestFile.m`
- **Functions Used**: `crop.m`, `interpbl.m`, `getSnr.m`
- **Description**: The raw data is preprocessed to enhance signal quality. This includes cropping waveforms to specified time windows, interpolating to a common grid, and calculating the SNR.

#### Step 3: Receiver Function Computation
- **Script**: `CompositeTestFile.m`
- **Functions Used**: `sparse_inverse_radon_fista.m`, `getEqData.m`
- **Description**: Receiver functions are computed from the preprocessed data. These functions represent the seismic response of the Earth's upper mantle and are crucial for detecting discontinuities.

#### Step 4: Radon Transform
- **Script**: `b*_fista_results.m`
- **Functions Used**: `sparse_inverse_radon_fista_synthetic.m`, `radon*d_forward_adjoint.m`
- **Description**: The Radon transform is applied to the receiver functions to detect key seismic features. The FISTA algorithm is used for sparse inverse Radon transform, which helps in identifying discontinuities like the Moho boundary.

#### Step 5: Visualization and Reporting
- **Script**: `CompositeTestFile.m`
- **Functions Used**: `m_proj.m`, `m_coast.m`, `saveResults.m`
- **Description**: Visualizations are generated using geographic data visualization functions from the `m_map/` module. Results are saved to `1_data/SRTFISTA/` in various formats (e.g., `.png`, `.eps`, `.mat`) for further analysis and reporting.

### Example Workflow

   ```matlab
   % Load raw seismic data from IRIS or local files
   data = irisFetch('BR_SGCB_RF.mat');
   ```

2. **Preprocess Data**:
   ```matlab
   % Crop waveforms to specified time windows
   ```
