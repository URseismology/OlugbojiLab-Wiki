## 3. Code Reference

### Main Scripts and Modules
- **plot_raydensity.m**:
  - **Description**: MATLAB script for visualizing ray path density across Africa.
  - **Input**: Seismic event data and station metadata.
  - **Output**: Geospatial visualization of ray paths using the `m_map` module.

- **main.ipynb**:
  - **Description**: Jupyter notebook for training a Wasserstein GAN to generate 2D images from MCMC-generated seismic models.
  - **Input**: MCMC-generated seismic models.
  - **Output**: Trained WGAN model and generated 2D images.

### Sub-Modules
- **fetch_EVENTS**:
  - **Description**: Retrieves and processes seismic event data from the IRIS FDSN web service.
  - **Scripts**:
    - `fetch_events.py`: Downloads seismic events based on specified criteria.
    - `process_events.py`: Preprocesses and formats the downloaded event data.

- **STN-EVENT-GENERATION**:
  - **Description**: Compiles detailed seismic event data and station metadata.
  - **Scripts**:
    - `compile_station_data.py`: Collects and processes station metadata.
    - `generate_event_catalog.py`: Creates a comprehensive event catalog from the processed data.

- **ss-precursors**:
  - **Description**: Performs forward modeling, seismic inversion, and geothermal analysis.
  - **Sub-Modules**:
    - `forward_modeling`:
      - **Scripts**:
        - `model_forward.py`: Simulates seismic wave propagation.
    - `seismic_inversion`:
      - **Scripts**:
        - `invert_seismic_data.py`: Inverts seismic data to estimate subsurface properties.
    - `geothermal_analysis`:
      - **Scripts**:
        - `analyze_geothermal_data.py`: Analyzes geothermal data for energy potential.

- **w-GAN**:
  - **Description**: Trains a Wasserstein GAN to generate 2D images from MCMC-generated seismic models.
  - **Sub-Modules**:
    - `data`:
      - **Scripts**:
        - `prepare_data.py`: Preprocesses and formats the MCMC-generated data for training.
    - `models`:
      - **Scripts**:
        - `wgan_model.py`: Defines the WGAN architecture and training loop.

- **DLOPy_v1.0**:
  - **Description**: Provides a framework for orientation determination using Rayleigh waves.
  - **Sub-Modules**:
    - `orientation_determination`:
      - **Scripts**:
        - `determine_orientation.py`: Determines the orientation of seismic sources based on Rayleigh wave data.

- **m_map**:
  - **Description**: Advanced geographic visualization module for MATLAB.
  - **Scripts**:
    - `m_map_functions.m`: Contains functions for creating geospatial maps and visualizations.

## 4. Workflows

### Data Retrieval and Preprocessing
1. **Seismic Event Data**:
   - **fetch_EVENTS/fetch_events.py**: Downloads seismic events from the IRIS FDSN web service.
   - **fetch_EVENTS/process_events.py**: Preprocesses and formats the downloaded event data.

2. **Station Metadata**:
   - **STN-EVENT-GENERATION/compile_station_data.py**: Collects and processes station metadata.
   - **STN-EVENT-GENERATION/generate_event_catalog.py**: Creates a comprehensive event catalog from the processed data.

### Advanced Analysis
1. **Forward Modeling**:
   - **ss-precursors/forward_modeling/model_forward.py**: Simulates seismic wave propagation using the preprocessed event and station data.

2. **Seismic Inversion**:
   - **ss-precursors/seismic_inversion/invert_seismic_data.py**: Inverts seismic data to estimate subsurface properties.

3. **Geothermal Analysis**:
   - **ss-precursors/geothermal_analysis/analyze_geothermal_data.py**: Analyzes geothermal data for energy potential.

### Visualization
1. **Ray Path Density**:
   - **plot_raydensity.m**: Uses the `m_map` module to visualize ray path density across Africa based on the preprocessed event and station data.

### Machine Learning
1. **Data Preparation**:
   - **w-GAN/data/prepare_data.py**: Preprocesses and formats the MCMC-generated seismic models for training.

2. **WGAN Training**:
   - **main.ipynb**: Trains a Wasserstein GAN using the prepared data to generate 2D images of seismic wave properties.

3. **Orientation Determination**:
   - **DLOPy_v1.0/orientation_determination/determine_orientation.py**: Determines the orientation of seismic sources based on Rayleigh wave data from the preprocessed event and station data.
