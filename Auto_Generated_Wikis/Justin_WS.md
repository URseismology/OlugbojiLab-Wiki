### `Data_Download_Yicheng-Copy*.ipynb`
This Jupyter notebook is the core of our data retrieval and processing workflow. It uses the Obspy library to connect to the FDSN web service and download waveform data for specific stations.

#### Key Functions and Steps
1. **Environment Setup**:
   - Import necessary libraries: `obspy`, `pandas`, etc.
   - Set up logging for detailed metadata recording.

2. **Data Retrieval**:
   - Define parameters for the FDSN query (network, station, channels, start time, duration).
   - Use Obspy to connect to the FDSN web service and retrieve waveform data.
   - Organize the retrieved data into an Obspy Stream object.

3. **Data Processing**:
   - Save each trace in the Stream object as an MSEED file.
   - Log metadata for each trace, including station information, start time, and duration.

4. **Example Code Snippet**:
   ```python
   import obspy
   from obspy.clients.fdsn import Client
   import pandas as pd

   # Set up FDSN client
   client = Client("IRIS")

   # Define query parameters
   network = "GE"
   station = "ISP"
   channels = ["BHZ", "BHN", "BHE"]
   start_time = obspy.UTCDateTime(2014, 7, 20, 18, 35, 0)
   duration = 1500

   # Retrieve waveform data
   st = client.get_waveforms(network, station, "*", channels, start_time, start_time + duration)

   # Save each trace as an MSEED file
   for tr in st:
       filename = f"{tr.id}.mseed"
       tr.write(filename, format="MSEED")

   # Log metadata
   metadata = []
   for tr in st:
       metadata.append({
           "station": tr.stats.station,
           "channel": tr.stats.channel,
           "start_time": tr.stats.starttime,
           "duration": tr.stats.npts / tr.stats.sampling_rate
       })
   pd.DataFrame(metadata).to_csv("metadata.csv", index=False)
   ```
