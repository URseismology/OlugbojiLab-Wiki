# Seismic Data Processing Suite

## 1. Project Overview

The **Seismic Data Processing Suite** is a comprehensive system designed for the retrieval, processing, analysis, and visualization of seismic data. The suite consists of four main sub-modules:

- **STATIONS_METADATA**: Processes and enriches station metadata with availability data.
- **Rover**: Automates the retrieval and processing of seismic data using tools like `rover` and `instaseis`.
- **GraphNoise**: Processes seismic data from GML files, updates station metadata, and generates detailed visualizations and monthly summaries.
- **polarisation-package**: Provides advanced tools for analyzing and visualizing seismic polarization properties.

The system is designed to handle large datasets efficiently and ensure high-quality data through rigorous filtering, cleaning, and validation processes. It leverages Python libraries and scripts for seamless data handling and processing, and it supports execution in both local and high-performance computing environments.

## 3. Code Reference

### STATIONS_METADATA
- **scripts/process_metadata.py**: Reads raw metadata, enriches it with availability data, and writes the processed metadata to a CSV file.
- **scripts/validate_data.py**: Validates the processed metadata and generates detailed validation reports.
- **scripts/generate_plots.py**: Generates visualizations of station metadata.

### Rover
- **scripts/retrieve_data.sh**: Shell script for activating the environment and running `rover` to retrieve seismic data.
- **scripts/process_data.py**: Python script for processing downloaded seismic data using `instaseis`.
- **scripts/schedule_jobs.py**: Python script for submitting batch jobs to SLURM.

### GraphNoise
- **scripts/update_metadata.py**: Updates station metadata with new information from GML files.
- **scripts/generate_visualizations.py**: Generates visualizations of seismic data and saves them as images or interactive plots.
- **scripts/summarize_monthly_activity.py**: Generates monthly summary reports of seismic activity.

### polarisation-package
- **polarisation/data_acquisition.py**: Module for acquiring raw seismic data.
- **polarisation/calculations.py**: Module for performing polarization calculations, including spectral and eigen-decomposition analyses.
- **polarisation/visualization.py**: Module for generating interactive visualizations of polarization properties.
