# Seismic Data Download and Analysis System

## 1. Project Overview

### Introduction
The **Seismic Data Download and Analysis System** is designed to automate the process of downloading, processing, and analyzing seismic data from the IRIS FDSN service. This system is particularly useful for both research purposes and practical applications such as early warning systems. The core components of this system include scripts for downloading data, correlating station coordinates with earthquake events, validating the downloaded data, managing batch jobs, and sending notifications upon task completion.

### Key Features
- **Automated Data Download**: Efficiently download seismic data using the IRIS FDSN service.
- **Station-Event Correlation**: Predict seismic wave arrival times by correlating station coordinates with earthquake events.
- **Data Integrity Check**: Validate downloaded data against the IRIS server to ensure accuracy.
- **Batch Job Management**: Leverage SLURM for efficient task management, especially in resource-constrained environments.
- **Real-time Notifications**: Receive email notifications upon task completion.

### Use Cases
- **Research**: Analyze seismic data for academic and scientific studies.
- **Early Warning Systems**: Implement real-time seismic monitoring and alert systems.
- **Educational Purposes**: Teach students about seismic data analysis and processing.

## 3. Code Reference

### Scripts Overview

#### `station2event.py`
**Purpose**: Correlate station coordinates with earthquake events to predict seismic wave arrival times.

**Functionality**:
- **Input**: Station coordinates and event data.
- **Output**: Predicted arrival times for seismic waves at each station.
- **Usage**:
  ```python
  python station2event.py --stations stations.csv --events events.csv --output predictions.csv
  ```

#### `integrity_check.py`
**Purpose**: Validate the downloaded data against the IRIS server to ensure accuracy.

**Functionality**:
- **Input**: Downloaded seismic data files.
- **Output**: Validation report indicating any discrepancies or missing data.
- **Usage**:
  ```python
  python integrity_check.py --data_path /path/to/data --report_path /path/to/report.txt
  ```

## 4. Workflows

### Data Flow Through Scripts

#### Step-by-Step Workflow

1. **Configuration Setup**:
   - Edit the `config.ini` file to specify paths and parameters.
   - Ensure all necessary input files (e.g., `stations.csv`, `events.csv`) are available.

2. **Batch Job Submission**:
   - Run `batch_rover.py` to submit batch jobs for downloading seismic data.
   ```python
   python batch_rover.py --config config.ini
   ```

3. **Data Download**:
   - The batch jobs execute, and seismic data is downloaded from the IRIS FDSN service.
   - Data is stored in the specified `data_path` directory.

4. **Station-Event Correlation**:
   - Run `station2event.py` to correlate station coordinates with earthquake events.
   ```python
   python station2event.py --stations stations.csv --events events.csv --output predictions.csv
   ```

5. **Data Integrity Check**:
   - Run `integrity_check.py` to validate the downloaded data against the IRIS server.
   ```python
   python integrity_check.py --data_path /path/to/data --report_path /path/to/report.txt
   ```

6. **Notification**:
   - Upon completion of the tasks, run `email.sh` to send email notifications.
   ```bash
   ./email.sh --status success --to recipient@example.com
   ```
