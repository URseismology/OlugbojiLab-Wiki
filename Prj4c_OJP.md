# Project Overview

## Introduction
The `ROOT` subsystem is a comprehensive suite designed for advanced seismic data processing and analysis, specifically tailored for the THBD project. It integrates various modules and tools to handle raw seismic data, perform complex analyses, and visualize results efficiently. The system is divided into three main sub-modules:

1. **2_Data**: Handles initial data preparation, including conversion from raw formats (e.g., SAC) to structured formats suitable for further analysis (e.g., MATLAB .mat files). It also supports advanced processing tools like ambient noise analysis and visualization of specific datasets.
2. **firevue-main**: Provides a utility for decoding HireVue interview questions from HAR files or encoded strings, offering a user-friendly tool for interview preparation.
3. **3_Src**: The core processing and analysis engine, containing advanced Python and MATLAB scripts for seismic data handling, including preprocessing, cross-correlation, station inventory management, and visualization.

## Objectives
- Convert raw seismic data into structured formats for analysis.
- Perform ambient noise analysis to extract meaningful signals.
- Visualize specific datasets for easier interpretation.
- Decode HireVue interview questions for better preparation.
- Provide a robust pipeline from raw data acquisition to detailed geological insights.
