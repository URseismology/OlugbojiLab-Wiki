# ROOT: Seismic Anisotropy Research in Africa

## 1. Project Overview

### Introduction
The **ROOT** project is a comprehensive, multi-language environment designed for advanced seismic anisotropy research and lithospheric studies in Africa. It integrates Fortran, C, MATLAB, and shell scripts to create a robust pipeline from model creation and data preprocessing to wave propagation calculations, FFT transformations, and visualization of seismic data. The project is divided into several modules that work together seamlessly to provide a cohesive framework for seismic data analysis.

### Objectives
- **Model Creation**: Generate synthetic models for seismic anisotropy.
- **Data Preprocessing**: Prepare real and synthetic seismic data for analysis.
- **Wave Propagation**: Perform wave propagation calculations using advanced numerical methods.
- **FFT Transformations**: Apply Fast Fourier Transforms (FFT) to analyze seismic signals.
- **Visualization**: Create detailed visualizations of seismic data and results.

### Key Features
- Multi-language support: Fortran, C, MATLAB, Shell scripts.
- Modular design: Each module can be used independently or in combination.
- High Performance Computing (HPC) integration: Optimized for parallel processing using Slurm.
- Comprehensive data visualization tools: Support detailed analysis and decision-making.
