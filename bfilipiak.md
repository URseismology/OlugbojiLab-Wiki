# Meteorological Data Analysis System Documentation

## 1. Project Overview

### Introduction
The Meteorological Data Analysis System is a comprehensive tool designed to analyze extreme weather events, particularly focusing on rainfall rates and total precipitation. This system integrates multiple datasets from various sources, including ASOS hourly observations, NOAA hourly data, GHCN daily climate data, and ASOS daily precipitation totals. The project aims to provide researchers with detailed numerical summaries and graphical representations that enable a deeper understanding of meteorological patterns and trends.

### Objectives
- **Data Integration**: Combine data from different sources to create a unified dataset.
- **Data Analysis**: Perform statistical analysis to identify extreme weather events.
- **Visualization**: Generate visual plots to illustrate recurrence intervals, exceedance probabilities, and other meteorological patterns.
- **Insight Generation**: Transform raw meteorological data into actionable insights for the study of extreme weather events.

### Key Features
- **Multi-source Data Handling**: Support for ASOS, NOAA, GHCN, and custom datasets.
- **Advanced Statistical Analysis**: Calculation of return periods (Tr) and exceedance probabilities (EP).
- **Graphical Visualization**: Generation of plots to visualize data trends and patterns.
- **Script Integration**: Use of both MATLAB and Python scripts for comprehensive analysis.

#### Python Scripts
- **Extreme_eval.py**
  ```python
  import pandas as pd

  def evaluate_extreme_events(file):
      # Read and process data
      data = pd.read_csv(file)
      processed_data = preprocess_data(data)
      return calculate_EP(processed_data)

  def preprocess_data(data):
      # Preprocess data (e.g., remove NaNs, convert units)
      data.dropna(inplace=True)
      return data

  def calculate_EP(data):
      # Calculate exceedance probability
      ep_values = data['precipitation'].rank(pct=True)
      return ep_values
  ```

  ```python
      # Read and process GHCN daily data

      processed_data = preprocess_data(data)
      return calculate_return_period(processed_data)

  def preprocess_data(data):
      # Preprocess data (e.g., remove NaNs, convert units)
      data.dropna(inplace=True)
      return data

  def calculate_return_period(data):
      # Calculate return period
      rp_values = data['precipitation'].rank(pct=False).apply(lambda x: 1 / x)
      return rp_values
  ```

  ```python
      # Split data by year
      grouped_data = data.groupby(data['date'].dt.year)
      for year, group in grouped_data:
  ```
