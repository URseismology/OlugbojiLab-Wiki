# Seismic Data Analysis Framework for the African Plate

## 1. Project Overview

### Introduction
The **Seismic Data Analysis Framework for the African Plate** is a comprehensive system designed to process, analyze, and visualize seismic data from the African Plate region. The framework integrates three primary sub-modules: `SS_PP`, `Combine_results`, and `Ps_RF`. Each module plays a crucial role in different stages of the seismic data analysis pipeline, ensuring a robust and scalable solution for researchers and geologists.

### Objectives
- **Automated Data Retrieval**: Efficiently retrieve seismic data from various sources.
- **Advanced Signal Analysis**: Apply sophisticated signal processing techniques like Multitaper Methods (MTC) and Markov Chain Monte Carlo (MCMC) algorithms.
- **Geological Contextualization**: Utilize geological datasets to provide context for seismic analyses.
- **Comparative Modeling**: Compare global seismic velocity models with the PREM model.
- **Visualizations**: Generate detailed visualizations of seismic properties and model comparisons.

### Key Features
- **End-to-End Pipeline**: From data retrieval to advanced analysis and visualization.
- **Modular Design**: Each sub-module can be used independently or in combination.
- **Scalability**: Designed to handle large datasets and run on high-performance computing clusters.
- **Geospatial Integration**: Incorporates geological data for contextual insights.

- **Seismic Data**: Raw seismic data is stored in the `SAC/Grid_Cells/Post_1_SNR/SHARP` directory. Each grid cell contains subdirectories for different runs and chains, storing logs, likelihoods, and ensemble results.
- **Geological Data**: Geological datasets are integrated into the `SS_PP` module to provide context for seismic analyses.
- **Seismic Models**: Global seismic velocity models (e.g., PREM) are stored in the `Combine_results/2_Data/Seismic_Models/Global_Models/PREM` directory.
