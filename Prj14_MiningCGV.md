# DLOPy: Seismic Instrument Orientation System

## 1. Project Overview

### Introduction
DLOPy is a comprehensive system designed for the automated determination of seismic instrument orientations using Rayleigh waves from both local and global data sources. The project leverages high-performance computing (HPC) environments to process large volumes of seismic data efficiently. DLOPy integrates multiple specialized modules, including data retrieval, orientation calculation, geodesic calculations, and job management.

### Key Features
- **Automated Orientation Determination**: Uses Rayleigh waves from local and global data sources.
- **High-Performance Computing (HPC) Integration**: Optimized for efficient resource usage on HPC clusters.
- **Geodesic Calculations**: Ensures precision in geographic computations.
- **Modular Architecture**: Easily extensible and maintainable.

### Use Cases
- Seismic monitoring stations need to accurately determine the orientation of their instruments.
- Research institutions require precise seismic data for geological studies.
- Disaster management agencies use accurate seismic data for early warning systems.

## 3. Code Reference

### Core Scripts
#### `Orient_PF.py`
- **Functionality**: Designs parameter files for orientation calculations.
- **Usage**:
  ```python
  python Orient_PF.py <input_file> <output_file>
  ```
- **Inputs**:
  - `<input_file>`: Path to the input data file.
  - `<output_file>`: Path to the output parameter file.

#### `readlocal.py`
- **Functionality**: Reads local seismic data and prepares it for processing.
- **Usage**:
  ```python
  python readlocal.py <data_directory>
  ```
- **Inputs**:
  - `<data_directory>`: Directory containing local seismic data files.

#### `run_orientations.ipynb`
- **Functionality**: Jupyter notebook for automated orientation calculations using global dispersion maps.
- **Usage**:
  - Open the notebook in a Jupyter environment and run the cells to perform orientation calculations.

#### `geographiclib`
- **Functionality**: Sub-module for geodesic calculations, ensuring precision in geographic computations.
- **Usage**:
  ```python
  from geographiclib.geodesic import Geodesic

  # Example: Calculate distance between two points
  result = Geodesic.WGS84.Inverse(lat1, lon1, lat2, lon2)
  distance = result['s12']
  ```

#### `finalangle.py`
- **Functionality**: Calculates the final orientation angles based on intermediate results.
- **Usage**:
  ```python
  python finalangle.py <input_file> <output_file>
  ```
- **Inputs**:
  - `<input_file>`: Path to the input file containing intermediate results.
  - `<output_file>`: Path to the output file for final angles.

### HPC Job Management
#### `tmp.sh`
- **Functionality**: Bash script for submitting jobs to the SLURM scheduler.
- **Usage**:

## 4. Workflows

### Data Flow Through Scripts

#### Step 1: Data Retrieval
- **Script**: `readlocal.py`
- **Input**: Directory containing local seismic data.
- **Output**: Processed data files ready for orientation calculations.

#### Step 2: Parameter File Design
- **Script**: `Orient_PF.py`
- **Input**: Input data file (e.g., processed from `readlocal.py`).
- **Output**: Parameter file for orientation calculations.

#### Step 3: Automated Orientation Calculation
- **Script**: `run_orientations.ipynb`
- **Input**: Parameter file and global dispersion maps.
- **Output**: Intermediate results of orientation calculations.

#### Step 4: Geodesic Calculations
- **Sub-module**: `geographiclib`
- **Functionality**: Ensures precision in geographic computations.
- **Usage**: Integrated into the main workflow to enhance accuracy.

#### Step 5: Final Angle Calculation
- **Script**: `finalangle.py`
- **Input**: Intermediate results from orientation calculations.
- **Output**: Final angles and metadata for seismic instrument orientations.

### HPC Job Submission Workflow
1. **Prepare Data**:
   - Use `readlocal.py` to process local seismic data.
   - Design parameter files using `Orient_PF.py`.

2. **Submit Job**:
   - Use the `tmp.sh` script to submit a job to the SLURM scheduler.
   - The job runs `run_orientations.ipynb`, which performs automated orientation calculations.

3. **Post-Processing**:
   - After the job completes, use `finalangle.py` to calculate the final angles.
   - Review and validate the results using statistical outputs and visualizations.
