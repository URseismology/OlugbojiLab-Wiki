## 4. Workflows

### Data Ingestion and Preprocessing Workflow
1. **Acquisition**:
   - Run `2_Data/West_Africa/data_acquisition.py` to download raw seismic data from IRIS.
   - Raw data is saved in `2_Data/West_Africa/RAW`.

2. **Preprocessing**:
   - Run `2_Data/West_Africa/preprocessing.py` to preprocess the raw data (filtering, trimming).
   - Preprocessed data is saved in `2_Data/West_Africa/Preprocessed`.

### Surface Wave Analysis Workflow
1. **Data Preparation**:
   - Ensure preprocessed data is available in `2_Data/West_Africa/Preprocessed`.

2. **Analysis**:
   - Run `Seislib/Obspy Scripts/preprocess_data.py` to further refine the data if needed.
   - Run `Seislib/surface_wave_analysis.py` to perform surface wave analysis.

3. **Visualization**:
   - Run `Seislib/PyGMT Scripts/plot_seismicity.py` to visualize the results.

### Moment Tensor Inversion Workflow
1. **Data Preparation**:
   - Ensure preprocessed data is available in `2_Data/West_Africa/Preprocessed`.

2. **Inversion**:
   - Run `MT_time/end_to_end_processing.py` for end-to-end seismic data processing and MT time-domain inversion.
   - Inversion results are saved in `MT_time/West_Africa/Inversion_Results`.

3. **Visualization**:
   - Run `3_Src/combined_scripts.py` to visualize the inversion results using combined MATLAB and Python scripts.

### Velocity Model Construction Workflow
1. **Data Preparation**:
   - Ensure seismic data is available for velocity model construction.

2. **Model Building**:
   - Run `Build_velocity_models/construct_model.py` to build a new velocity model.
   - Run `Build_velocity_models/modify_model.py` to modify an existing velocity model.

### Advanced Signal Processing Workflow
1. **Data Preparation**:
   - Ensure preprocessed data is available in `2_Data/West_Africa/Preprocessed`.

2. **Signal Processing**:
   - Run `4_Bin/focal_mechanism_inversion.py` for focal mechanism inversion.
   - Run `4_Bin/spectrogram_generation.py` to generate spectrograms from seismic data.

### Example Workflow: End-to-End Seismic Data Analysis
1. **Data Acquisition**:
   - Run `2_Data/West_Africa/data_acquisition.py` to download raw seismic data.
   - Raw data is saved in `2_Data/West_Africa/RAW`.

2. **Preprocessing**:
   - Run `2_Data/West_Africa/preprocessing.py` to preprocess the raw data.
   - Preprocessed data is saved in `2_Data/West_Africa/Preprocessed`.

3. **Surface Wave Analysis**:
   - Run `Seislib/surface_wave_analysis.py` to perform surface wave analysis on preprocessed data.

4. **Moment Tensor Inversion**:
   - Run `MT_time/end_to_end_processing.py` for end-to-end seismic data processing and MT time-domain inversion.
   - Inversion results are saved in `MT_time/West_Africa/Inversion_Results`.

5. **Velocity Model Construction**:
   - Run `Build_velocity_models/construct_model.py` to build a new velocity model.

6. **Advanced Signal Processing**:
   - Run `4_Bin/focal_mechanism_inversion.py` for focal mechanism inversion.
   - Run `4_Bin/spectrogram_generation.py` to generate spectrograms from seismic data.

7. **Visualization**:
   - Run `Seislib/PyGMT Scripts/plot_seismicity.py` to visualize the surface wave analysis results.
   - Run `3_Src/combined_scripts.py` to visualize the moment tensor inversion results using combined MATLAB and Python scripts.

This structured workflow ensures a systematic approach to seismic data analysis, from data acquisition to advanced visualization.
