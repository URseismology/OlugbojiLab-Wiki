# Seismic Data Analysis Project

## 1. Project Overview

The **Seismic Data Analysis Project** is a comprehensive suite of MATLAB and Python scripts designed for advanced seismic data processing, focusing on techniques like CRISP-RF and FISTA to analyze seismic signals from African stations. The project aims to provide a robust workflow for geophysical research, from raw data acquisition to detailed analysis and visualization.

### Key Features:
- **CRISP-RF (Common Receptor Impulse Response - Receiver Functions) Analysis**: Advanced signal processing techniques to extract and analyze receiver functions.
- **FISTA (Fast Iterative Shrinkage-Thresholding Algorithm)**: Optimization algorithm for solving inverse problems in seismic data.
- **Data Preprocessing**: Automated scripts for downloading, cleaning, and formatting seismic data from various sources.
- **Visualization**: Tools for generating intuitive visualizations of seismic signals, vespagrams, and geological structures.

### Components:
1. **Figure4_Sequenced_Seismograms**: Visualizes seismic data across different geological eras.
2. **ss_precursors**: Generates vespagrams from synthetic seismograms.
3. **Old_Analyses**: Supports RF imaging and visualization of past analyses.
4. **2_Data**: Automates the process of downloading and preprocessing seismic data.
5. **3_Src**: Offers advanced tools for clustering, geospatial visualization, and seismic analysis.
6. **Telewavesim**: Simulates and visualizes seismic signals.
