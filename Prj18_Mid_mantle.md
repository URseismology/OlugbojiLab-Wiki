# Seismic Data Processing and Visualization Project

## 1. Project Overview

This project is designed to facilitate advanced seismic data processing, modeling, and visualization using both MATLAB and Python environments. The primary focus is on understanding the Earth's mid-mantle by performing various geophysical analyses such as reflection/transmission coefficient calculations, synthetic receiver function generation, travel time analysis, and moment tensor inversion. The root directory serves as a central hub for managing these activities, with specialized sub-modules handling specific tasks.

The data files are primarily seismic waveforms in SAC format. The file naming convention is as follows:
