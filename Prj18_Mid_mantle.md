## 3. Code Reference

### Scripts and Their Functions

#### ROOT
- **main.m**: Main script that initializes the environment and orchestrates the processing pipeline.
- **setup_environment.m**: Sets up necessary paths, dependencies, and configurations.
- **run_jobs.py**: Python script for automating batch jobs and data processing tasks.

#### Global_mid_mantle
- **Global_SS**
  - **ss_reflections.m**: Performs shear-wave reflection analysis using advanced signal processing techniques.
  - **plot_ss_reflections.m**: Generates visualizations of the shear-wave reflections.
- **2_Data**
  - **verify_data.m**: Verifies that all necessary data files are present and processed.
  - **data_preprocessing.py**: Preprocesses raw seismic data for further analysis.
- **Tolu_Global**
  - **global_simulations.m**: Runs geophysical simulations for global seismological analysis.
  - **plot_global_maps.m**: Generates global maps of seismic properties.

#### utils
- **travel_time_calculator.m**: Calculates travel times using the PREM model.
- **seismic_modeling.m**: Performs detailed seismic modeling and inversion.
- **receiver_functions.m**: Generates synthetic receiver functions for seismic data analysis.

#### Figures_4pub
- **generate_figures.m**: Generates high-quality figures for research publications.
  - **plot_receiver_functions.m**: Plots receiver functions.
  - **plot_mantle_tomography.m**: Plots mantle tomography results.
- **figure_utilities.py**: Python utilities for figure generation and formatting.

## 4. Workflows

### Data Flow Through the Scripts

1. **Initialization and Setup**
   - **main.m** initializes the environment by calling `setup_environment.m`.
   - **setup_environment.m** sets up necessary paths, dependencies, and configurations.
   - **run_jobs.py** is used to automate batch jobs and data processing tasks.

2. **Data Verification and Preprocessing**
   - **verify_data.m** in the `2_Data` directory checks for the presence of all necessary data files.
   - **data_preprocessing.py** preprocesses raw seismic data, ensuring it is ready for analysis.

3. **Seismic Analysis**
   - **ss_reflections.m** in the `Global_SS` directory performs shear-wave reflection analysis.
   - **global_simulations.m** in the `Tolu_Global` directory runs geophysical simulations for global seismological analysis.
   - **travel_time_calculator.m** and **seismic_modeling.m** in the `utils` directory perform detailed travel time calculations and seismic modeling.

4. **Synthetic Receiver Function Generation**
   - **receiver_functions.m** in the `utils` directory generates synthetic receiver functions for seismic data analysis.

5. **Visualization and Publication**
   - **generate_figures.m** in the `Figures_4pub` directory generates high-quality figures for research publications.
     - **plot_receiver_functions.m** plots receiver functions.
     - **plot_mantle_tomography.m** plots mantle tomography results.
   - **figure_utilities.py** provides additional utilities for figure generation and formatting.

### Example Workflow

1. **Initialize the Environment**
   ```matlab
   main;
   ```

2. **Verify and Preprocess Data**
   ```matlab
   verify_data;
   data_preprocessing;
   ```

3. **Perform Seismic Analysis**
   ```matlab
   ss_reflections;
   global_simulations;
   travel_time_calculator;
   seismic_modeling;
   receiver_functions;
   ```

4. **Generate Figures for Publication**
   ```matlab
   generate_figures;
   plot_receiver_functions;
   plot_mantle_tomography;
   ```

By following this structured workflow, the project ensures a systematic and efficient approach to seismic data processing, modeling, and visualization.
