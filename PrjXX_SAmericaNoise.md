# ROOT Subsystem: Seismic Data Management and Analysis Framework

## 1. Project Overview

The `ROOT` subsystem is a comprehensive, modular framework designed for efficient seismic data management and analysis in an HPC (High-Performance Computing) environment. It is specifically tailored for tasks such as ambient noise cross-correlation function (CCF) analysis, seismic data processing, signal filtering, and advanced analyses like dispersion curve calculation. The system leverages the Bluehive supercomputer for parallel processing and ensures robust data management through automated retrieval, validation, and reporting mechanisms.

### Key Features:
- **Modular Design**: Composed of four main sub-modules: `6_Testings`, `2_Data`, `3_Src`, and `4_Bin/obspy`.
- **Parallel Processing**: Utilizes SLURM job scheduling for efficient parallel processing on the Bluehive supercomputer.
- **Data Integrity**: Ensures data integrity through automated retrieval, validation, and metadata generation.
- **Advanced Analysis**: Supports advanced seismic analysis techniques such as CCF calculation and dispersion curve analysis.

## 3. Code Reference

### 3.1 `6_Testings` Module
The `6_Testings` module focuses on advanced seismic analysis techniques such as CCF calculation and dispersion curve analysis.

- **`ccf_analysis.py`**: Performs cross-correlation function (CCF) analysis on seismic data.
- **`dispersion_curve.py`**: Calculates dispersion curves from CCF results.
- **`parallel_processing.sh`**: SLURM job script for parallel processing of CCF and dispersion curve calculations.

### 3.2 `2_Data` Module
The `2_Data` module automates the retrieval, processing, and management of seismic data.

- **`data_retrieval.py`**: Script to download raw seismic data using Obspy's rover tool.
- **`data_validation.py`**: Validates downloaded data and generates reports for any issues.
- **`data_archival.py`**: Archives validated data and moves active datasets to the appropriate directories.
- **`slurm_jobs.sh`**: SLURM job script for parallel processing of seismic data.

### 3.3 `3_Src` Module
The `3_Src` subsystem sets up a specialized Python environment for seismic analysis and manages large-scale data downloads.

- **`environment_setup.py`**: Sets up the required Python environment and installs necessary packages.
- **`data_management.py`**: Manages data downloads, monitors job performance, and preprocesses raw station data.
- **`config.ini`**: Central configuration file containing settings for data retrieval, processing, and analysis.

### 3.4 `4_Bin/obspy` Module
The `4_Bin/obspy` module automates data retrieval using Obspy's rover tool and ensures data integrity.

- **`download_data.py`**: Script to download seismic data from repositories.
- **`validate_data.py`**: Performs integrity checks on downloaded data and generates metadata.
- **`send_email.py`**: Sends email notifications for job completion and any issues detected during processing.

## 4. Workflows

1. **Initialize Environment**:
   - Run `environment_setup.py` to set up the Python environment and install necessary packages.
2. **Download Data**:
   - Execute `download_data.py` to retrieve raw seismic data from repositories using Obspy's rover tool.
3. **Validate Data**:
   - Run `validate_data.py` to perform integrity checks on the downloaded data and generate metadata.
4. **Archive Data**:
   - Use `data_archival.py` to archive validated data in the `archive/EC-ANTS` directory and move active datasets to the `active/EC-ANTS` directory.

### 4.2 Data Processing Workflow
1. **Prepare Active Datasets**:
   - Ensure that the active datasets are correctly placed in the `active/EC-ANTS` directory.
2. **Submit SLURM Jobs**:
   - Submit SLURM jobs using `slurm_jobs.sh` to process the active datasets in parallel.
3. **Perform Advanced Analysis**:
   - Use `ccf_analysis.py` to perform cross-correlation function (CCF) analysis on the processed data.
   - Run `dispersion_curve.py` to calculate dispersion curves from CCF results.
4. **Generate Reports and Notifications**:
   - Generate reports for any issues detected during processing.
   - Send email notifications using `send_email.py` for job completion and any issues.

### 4.3 Data Management Workflow

   - Use the `data_management.py` script to monitor the performance of ongoing jobs and ensure efficient data processing.
