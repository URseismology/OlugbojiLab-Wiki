# Seismic Data Analysis Framework

## 1. Project Overview

This project is a comprehensive seismic data analysis framework designed to automate instrument orientation, download and process seismic data, and perform advanced seismic studies using machine learning and MCMC simulations. The primary objectives are:

- **Automated Instrument Orientation**: Determine the orientation of seismic instruments using Rayleigh waves.
- **Data Collection**: Download and preprocess seismic data from the IRIS database for US-based stations.
- **Advanced Seismic Analysis**: Perform reflectivity function modeling, travel time tomography, and synthetic data generation.

The project is structured into several key components:

- **OBS_Orientations**: Specializes in automated orientation analysis using Rayleigh waves.
- **JapaneseProject**: Offers a suite of scripts for comprehensive seismic data analysis, including visualization and synthetic data generation.
- **3_Src**: Integrates machine learning and MCMC simulations for advanced seismic travel time tomography and reflectivity function modeling.

  import obspy
  from obspy.signal.invsim import simulate_seismometer
  from obspy.geodetics import gps2dist_azimuth
  import numpy as np

  def determine_orientation(st, freq_band):
      """
      Determine the orientation of seismic instruments using Rayleigh waves.
      
      :param st: ObsPy Stream object containing seismic data.
      :param freq_band: Frequency band for analysis.
      :return: Orientation angle in degrees.
      """
      # Preprocess data
      st.detrend('demean')
      st.taper(max_percentage=0.05, type='cosine')

      # Filter data
      st.filter('bandpass', freqmin=freq_band[0], freqmax=freq_band[1])

      # Calculate Rayleigh wave phase velocity
      dist, azim = gps2dist_azimuth(st[0].stats.sac.stla, st[0].stats.sac.stlo,
                                     st[0].stats.sac.evla, st[0].stats.sac.evlo)
      phase_velocity = dist / (st[0].stats.starttime - st[0].stats.endtime)

      # Determine orientation
      orientation_angle = np.arctan2(st[1].data, st[0].data) * 180 / np.pi

      return orientation_angle

  if __name__ == "__main__":

  import numpy as np

  def generate_synthetic_data(num_samples, freq_band):
      """
      Generate synthetic seismic data.
      
      :param num_samples: Number of samples in the synthetic data.
      :param freq_band: Frequency band for the synthetic data.
      :return: Synthetic seismic data.
      """
      t = np.linspace(0, 1, num_samples)
      f_min, f_max = freq_band
      frequencies = np.random.uniform(f_min, f_max, num_samples)
      
      synthetic_data = np.sin(2 * np.pi * frequencies * t) + np.random.normal(0, 0.1, num_samples)
      
      return synthetic_data

- **travel_time_tomography.py**
  ```python
  import numpy as np
  from scipy.optimize import minimize

  def travel_time_residuals(params, data):
      """
      Calculate the residuals for travel time tomography.
      
      :param params: Model parameters.
      :param data: Observed travel times.
      :return: Residuals.
      """
      model = params[0] * np.exp(-params[1] * data)
      residuals = data - model
      
      return residuals

  def perform_tomography(data):
      """
      Perform travel time tomography using the Levenberg-Marquardt algorithm.
      
      :param data: Observed travel times.
      :return: Optimized model parameters.
      """
      initial_guess = [1.0, 0.1]
      result = minimize(travel_time_residuals, initial_guess, args=(data), method='lm')
      
      return result.x

  if __name__ == "__main__":
      data = np.load("JapaneseProject/ProcData/travel_times.npy")
      
      optimized_params = perform_tomography(data)
      
      print(f"Optimized model parameters: {optimized_params}")
  ```

## 4. Workflows

### Data Collection Workflow
1. **Download Seismic Data**:
   - Run `download_US_stations.py` to download raw seismic data from the IRIS database.
   - The script saves the data in the `2_Data/SAC` directory.

### Data Preprocessing Workflow
1. **Preprocess Raw Data**:
   - Run `preprocess_data.py` to detrend and taper the raw SAC files.
   - The preprocessed data is saved in the `JapaneseProject/ProcData` directory.

### Instrument Orientation Workflow
1. **Determine Instrument Orientation**:
   - Run `OBS_Orientations.py` to determine the orientation of seismic instruments using Rayleigh waves.
   - The script processes the data and saves the results in the `OBS_Orientations/data/processed` directory.

### Advanced Seismic Analysis Workflow
1. **Generate Synthetic Data**:
   - Run `synthetic_data.py` to generate synthetic seismic data for testing and validation.
   - The synthetic data is saved in a NumPy file within the `3_Src` directory.

2. **Perform Travel Time Tomography**:
   - Run `travel_time_tomography.py` to perform travel time tomography using the processed data from `JapaneseProject/ProcData`.
   - The optimized model parameters are printed and can be used for further analysis.

### Visualization Workflow
1. **Generate Visualizations**:
   - Use the scripts in the `JapaneseProject/Images` directory to generate visualizations and plots.
   - The visualizations are saved in the `Images` subdirectory for easy access and review.

By following these workflows, you can efficiently collect, preprocess, analyze, and visualize seismic data using this comprehensive framework.
