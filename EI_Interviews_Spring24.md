# AI Documentation for Seismic Research & Synthetic Data Generation

## 1. Project Overview

### Introduction
The `ROOT` subsystem is a comprehensive framework designed to address two primary scientific challenges: synthetic data generation using Generative Adversarial Networks (GANs) and seismic data processing through ambient noise cross-correlation analysis. The project is divided into two main modules:

- **Prj_GAN**: Focuses on developing a Wasserstein GAN (WGAN) to generate high-quality synthetic data for Monte Carlo ensembles.
- **Prj_GPU**: Provides a MATLAB-based framework for seismic data processing, specifically ambient noise cross-correlation analysis.

### Objectives
- **Synthetic Data Generation**: Develop and train a WGAN to produce synthetic data that closely matches real distributions, enhancing the robustness of Monte Carlo simulations.
- **Seismic Data Analysis**: Automate the preprocessing and analysis of seismic data using ambient noise cross-correlation techniques to derive meaningful insights into geological structures.

### Key Features
- **Advanced GAN Architecture**: Utilizes a Wasserstein GAN with gradient penalty for improved stability and performance.
- **Data Normalization and Slicing**: Efficiently preprocesses input data for better training outcomes.
- **Experiment Tracking**: Integrates Weights & Biases (W&B) for tracking experiments and visualizing results.
- **Seismic Data Processing**: Automates cross-correlation function (CCF) calculations with extensive preprocessing steps.
- **Modular Design**: Both modules are designed to be modular, allowing for easy integration and extension.

### Data Patterns
- **Prj_GAN/DATA**: Contains the input data for the GAN, including downsampled points and Rayleigh wave data.
  - `downsampled_points.csv`: A CSV file with downsampled points.
  - `Rayleigh_P*_downsampled_flat.csv`: A large CSV file containing Rayleigh wave data.

- **Prj_GAN/MODEL**: Stores the trained GAN models.
  - `WGAN_Simple_epoch*.model`: Model checkpoints at different epochs.

- **Prj_GPU/DATA**: Houses seismic data in SAC format and metadata files.
  - `DataG/EVO/` and `DataG/TAM/`: Subdirectories containing seismic data for specific stations (EVO and TAM).
    - Files are named according to the station, channel, and time information.
  - `node_location.csv`: Metadata file with node locations.
  - `node_alive.csv`: Metadata file indicating which nodes are active.

- **Prj_GPU/RESULTS**: Stores results from seismic data processing.
  - `ccf_auto/figs/window4hr/G-EVO_G-TAM.ps`: PostScript files of CCF plots.
  - `ccf_auto/text_output/LoveResponse/dispersion_G-EVO_G-TAM.txt`: Text files with dispersion data for Love waves.
  - `ccf_auto/text_output/RayleighResponse/dispersion_G-EVO_G-TAM.txt`: Text files with dispersion data for Rayleigh waves.
  - `ccf_auto/ccf_log/G-EVO_G-TAM.txt`: Log files of CCF calculations.

## 3. Code Reference

### Prj_GAN/SCRIPTS
#### `generative_model.py`
- **Purpose**: Implements the Wasserstein GAN with gradient penalty (WGAN-GP) for synthetic data generation.
- **Key Functions**:
  - `build_generator()`: Constructs the generator network.
  - `build_critic()`: Constructs the critic network.
  - `train_gan()`: Trains the GAN model using a dataset and logs results to Weights & Biases (W&B).
  - `generate_synthetic_data()`: Generates synthetic data using the trained generator.

#### `process_data.py`
- **Purpose**: Preprocesses input data for GAN training.
- **Key Functions**:
  - `normalize_data(data)`: Normalizes the input data to a standard range.
  - `slice_data(data, slice_size)`: Slices the data into smaller segments for batch processing.

#### `train_evaluate.ipynb`
- **Purpose**: Orchestrates the training and evaluation process of the GAN model.
- **Key Steps**:
  - Loads and preprocesses input data using `process_data.py`.
  - Trains the GAN model using `generative_model.py`.
  - Evaluates the generated synthetic data against real data distributions.

#### `result_eval.ipynb`
- **Purpose**: Analyzes and visualizes the results of the GAN training.
- **Key Steps**:
  - Loads the trained GAN model.
  - Generates new synthetic data.
  - Compares the statistical properties of synthetic and real data using various metrics (e.g., histograms, scatter plots).

### Prj_GPU/CODE
#### `Stp2_doCCF.m`
- **Purpose**: Automates the calculation of cross-correlation functions (CCFs) for seismic data.
- **Key Steps**:
  - Loads seismic data from SAC files.
  - Preprocesses the data by applying filters, normalization, and tapering.
  - Computes CCFs using the `doCCF` function.
  - Saves results to specified output directories.

- **Purpose**: Sets up the directory structure and initializes parameters for seismic data processing.
- **Key Steps**:

  - Defines paths and filenames for input and output files.
  - Initializes parameters for CCF calculations.

#### Functions in `functions/`
- **`load_sac.m`**: Loads SAC format seismic data.
- **`rotate_vector.m`**: Rotates vectors to align with specific axes.
- **`runwin_norm.m`**: Normalizes data within a running window.
- **`cos_taper.m`**: Applies a cosine taper to the data.
- **`doCCF.m`**: Computes cross-correlation functions.
- **`FiltFiltM.m`**: Applies forward and backward filtering to the data.
- **`read_SACPZ.m`**: Reads SAC pole-zero files for filter coefficients.
- **`rm_SACPZ.m`**: Removes the effect of SAC pole-zero filters from the data.
- **`readsac.m`**: Reads SAC format seismic data.
- **`FTN.m`**: Computes the Fast Fourier Transform (FFT) and Normalization.
- **`get_filter_TFcoeffs.m`**: Retrieves filter transfer function coefficients.

## 4. Workflows

### Data Flow in Prj_GAN
1. **Data Preparation**:
   - Load raw data from `Prj_GAN/DATA`.
   - Preprocess the data using `process_data.py`.

2. **Model Training**:
   - Train the WGAN model using `generative_model.py` and `train_evaluate.ipynb`.
   - Track experiments and log results to Weights & Biases (W&B).

3. **Synthetic Data Generation**:
   - Generate synthetic data using the trained generator.
   - Evaluate the quality of synthetic data against real data distributions.

4. **Result Analysis**:
   - Visualize and analyze the generated data using `result_eval.ipynb`.

### Data Flow in Prj_GPU
1. **Data Preparation**:
   - Load seismic data from `Prj_GPU/DATA/DataG`.
   - Preprocess the data using functions like `load_sac.m`, `runwin_norm.m`, and `cos_taper.m`.

2. **Parameter Initialization**:
   - Initialize parameters and set up directories using `stp1_initParams.m`.

3. **Cross-Correlation Function Calculation**:
   - Compute CCFs using `Stp2_doCCF.m` and the `doCCF` function.
   - Apply filters and normalization to ensure accurate results.

4. **Result Storage**:
   - Save CCF plots in `Prj_GPU/RESULTS/ccf_auto/figs`.
   - Store dispersion data in `Prj_GPU/RESULTS/ccf_auto/text_output`.

5. **Log Management**:
   - Log the details of each CCF calculation in `Prj_GPU/RESULTS/ccf_auto/ccf_log`.

### Integration and Collaboration
- **Data Sharing**: Ensure that synthetic data generated by `Prj_GAN` can be used as input for seismic data processing in `Prj_GPU`.
- **Cross-Validation**: Validate the results from both modules to ensure consistency and accuracy.
- **Documentation**: Maintain detailed documentation and logs for reproducibility and future reference.
