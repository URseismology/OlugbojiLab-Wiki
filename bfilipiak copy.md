## 1. Project Overview

### Purpose
The AI Weather Analysis System is a sophisticated tool designed to analyze and visualize weather data from multiple sources, including ASOS (Automated Surface Observing System), NOAA (National Oceanic and Atmospheric Administration), and GHCN (Global Historical Climatology Network). The system focuses on advanced statistical evaluations of extreme events, daily and hourly metrics, and longitudinal trends.

### Key Features
- **Data Ingestion**: Efficiently reads raw data from various sources.
- **Data Processing**: Computes return periods, exceedance probabilities, and other statistical metrics.
- **Visualization**: Generates insightful graphs and plots to visualize the analyzed data.
- **Modular Design**: Each component is designed to be independently updated or extended, ensuring flexibility and maintainability.

### Use Cases
- **Extreme Event Analysis**: Identifying and analyzing rare weather events.
- **Longitudinal Studies**: Tracking weather patterns over time.
- **Comparative Analysis**: Comparing data from different sources for consistency and accuracy.

## 2. Data Architecture

### Directory Structure
The project is organized into several key directories, each serving a specific purpose:

- **ROOT/**: Root directory containing general files.
- **plots/**: Contains generated plots and visualizations.
- - **Final_plots/**: Finalized plots ready for presentation or publication.
- - **Test plots/**: Experimental or intermediate plots used during development.
- **scripts/**: Contains all the Python and MATLAB scripts for data processing, analysis, and visualization.
- **data/**: Stores raw and processed data files.
- - **testdata/**: Sample datasets for testing and validation.

### Data Patterns
The data is organized in a structured manner to facilitate easy access and efficient processing:

- **CSV Files**: Raw and processed data are stored in CSV format, making them easily readable by both Python and MATLAB scripts.
- **MAT Files**: Intermediate data structures and results from statistical computations are saved in MAT files for quick loading during subsequent analyses.
- **PNG and FIG Files**: Visualizations are saved as PNG files for web and document integration, and FIG files for further editing in MATLAB.
