## 1. Project Overview

The `ROOT` subsystem is a comprehensive suite designed to support advanced seismic wave propagation simulations, spectral analysis, and data processing for geophysical research and engineering applications. It integrates several key sub-modules that work together to provide a robust and scalable workflow from data preparation to simulation execution and detailed analysis.

### Key Features:
- **Seismic Wave Propagation Simulations**: Advanced modeling of seismic waves.
- **Spectral Analysis**: Robust tools for spectral analysis, including multitaper methods.
- **Data Processing**: Efficient handling of large datasets and parallel computing.
- **Machine Learning Models**: Integration of machine learning techniques for data analysis.
- **Visualization**: Tools for visualizing simulation results and analysis outcomes.

### Sub-Modules:

3. **epic_related**: Randomized force simulations and signal analysis.

## 4. Workflows

### Data Flow and Script Interactions
The `ROOT` subsystem follows a well-defined workflow that ensures data flows seamlessly through different stages of processing and analysis.

#### Data Preparation
1. **Data Collection**: Collect seismic data from various sources.
2. **Data Cleaning**: Clean and preprocess the data using scripts in `multitaper_code` and `EP_bliu`.
3. **Data Organization**: Organize the cleaned data into appropriate directories.

#### Simulation Execution
1. **Configuration Setup**: Set up configuration files for experiments in `epic_production/experiments/experiment_*/configs/`.
2. **Data Preparation**: Use `prepare_data.sh` to prepare data for simulation.
3. **Simulation Run**: Execute simulations using `run_large_scale_simulation.sh` and `run_experiment.py`.

#### Data Analysis
1. **Spectral Analysis**: Perform spectral analysis using `multitaper_analysis.m` and `rayleigh_wave_modeling.m`.
2. **Signal Analysis**: Analyze signals using `signal_analysis.py` in `epic_related`.
3. **FTAN Processing**: Process FTAN data using `ftan_processing.py` in `EP_bliu`.

#### Machine Learning
1. **Model Training**: Train machine learning models on simulation data using `train_ml_model()` in `epic_production`.
2. **Model Evaluation**: Evaluate the trained models and refine as necessary.

#### Visualization
1. **Result Plotting**: Visualize results using `plot_spectrum()`, `plot_results()`, and `visualize_results.py`.
