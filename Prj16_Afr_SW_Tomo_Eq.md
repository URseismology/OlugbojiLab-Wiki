## 3. Code Reference

### Python_jupyter/Seislib
#### Jupyter Notebooks
- **download_data.ipynb**
  ```python
  import obspy
  from obspy.clients.fdsn import Client
  from obspy.core import UTCDateTime

  # Initialize FDSN client
  client = Client("IRIS")

  # Define event parameters
  start_time = UTCDateTime("2009-01-01T00:00:00")
  end_time = UTCDateTime("2009-01-01T01:00:00")
  network = "IU"
  station = "ANTO"

  # Download data
  st = client.get_waveforms(network, station, "*", "BH?", start_time, end_time)

  # Save data to file
  st.write(f"datacache/{start_time.strftime('%Y%m%d_%H%M%S')}/data.sac", format="SAC")
  ```

- **preprocess_data.ipynb**
  ```python
  import obspy

  # Load data
  st = obspy.read("datacache/20090101_123456/data.sac")

  # Preprocess data
  st.detrend("demean")

  # Save processed data
  st.write("datacache/20090101_123456/data_processed.sac", format="SAC")
  ```

  function process_data(event_dir)
      % Load SAC data
      sac_file = fullfile(event_dir, 'data_processed.sac');
      data = sacread(sac_file);

## 4. Workflows

### Data Flow Through Scripts

1. **Data Downloading and Preprocessing**
   - **Step 1**: Jupyter notebooks in `Python_jupyter/Seislib` download raw seismic data from the IRIS FDSN server.
     ```python
     client.get_waveforms(network, station, "*", "BH?", start_time, end_time)
     ```
   - **Step 2**: Raw data is saved to the `datacache` directory in SAC format.
     ```python
     st.write(f"datacache/{start_time.strftime('%Y%m%d_%H%M%S')}/data.sac", format="SAC")
     ```
   - **Step 3**: Data is preprocessed using another Jupyter notebook.
     ```python
     st.detrend("demean")
     st.filter("bandpass", freqmin=0.1, freqmax=1.0)
     st.write("datacache/20090101_123456/data_processed.sac", format="SAC")
     ```

2. **Seismic Analysis with MINEOS and TPW**
   - **Step 4**: MATLAB scripts in `Matlab/ASWMS-Q-master` load the processed data from the `datacache` directory.
     ```matlab
     data = sacread(fullfile(event_dir, 'data_processed.sac'));
     ```
   - **Step 5**: Additional processing (e.g., filtering) is performed and data is saved in MATLAB format.
     ```matlab
     save(mat_file, 'data_filtered');
     ```
   - **Step 6**: MINEOS models are run using the processed data.
     ```matlab
     system(['MINEOS -i ', data_file, ' -o ', output_dir]);
     ```
   - **Step 7**: Results from MINEOS are post-processed and visualized.
     ```matlab
     plot(results.time, results.amplitude);
     saveas(gcf, fullfile(output_dir, 'amplitude_plot.pdf'));
     ```
   - **Step 8**: TPW models are run using the same data.
     ```matlab
     system(['TPW -i ', data_file, ' -o ', output_dir]);
     ```
   - **Step 9**: Results from TPW are post-processed and visualized.
     ```matlab
     plot(results.distance, results.amplitude);
     saveas(gcf, fullfile(output_dir, 'amplitude_distance_plot.pdf'));
     ```

3. **Visualization**
   - **Step 10**: Output figures are generated and stored in the `OUT/figs/eventmaps` directory.
     - Event location maps
     - Back azimuth plots
     - Amplitude-time and amplitude-distance plots
