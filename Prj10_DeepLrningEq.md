## 4. Workflows

### Data Flow through the Scripts

1. **Data Retrieval**
   - **Shell Script**: `retrieve_data.sh` fetches data from remote servers and stores it in a local directory.
   - **MATLAB Script**: `real_time_analysis.m` or `historical_data_analysis.m` reads the data for processing.

2. **Data Preprocessing**
   - **Python Script**: `preprocess_data.py` converts raw seismic data into a format suitable for analysis.
   - **Shell Script**: `preprocess_data.sh` automates the preprocessing step.

3. **Event Analysis**
   - **Python Script**: `event_analysis.py` identifies significant events from the processed data.
   - **MATLAB Script**: `signal_noise_filtering.m` filters noise from seismic signals to improve event detection.

4. **Model Training and Inference**
   - **Python Script**: `data_preparation.py` prepares datasets for training.
   - **Python Script**: `model_training.py` trains a CNN model on the prepared data.
   - **Python Script**: `phase_detection.py` uses the trained model to detect phases in new seismic data.

5. **Data Visualization**
   - **Python Script**: `visualize_data.py` generates interactive visualizations of the processed data.
   - **MATLAB Script**: `plot_seismic_data.m` creates detailed plots for analysis and reporting.

6. **Data Management**
   - **Shell Script**: `check_disk_usage.sh` monitors disk usage to ensure efficient storage.
   - **Shell Script**: `backup_data.sh` backs up important seismic data to a remote server.
